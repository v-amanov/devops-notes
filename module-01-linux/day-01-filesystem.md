## Ключевые команды Дня 1
- `pwd` — показать текущую директорию
- `mkdir -p` — создать вложенные папки рекурсивно
- `cp source destination` — копировать файл
- `cat file` — показать содержимое файла
- `whoami` и `id` — узнать информацию о пользователе
- `cat /etc/passwd` — посмотреть всех пользователей системы
- `cat /etc/group` — посмотреть все группы

## Ошибки и решения
- `mkdir: Permission denied` в `/home` → создавать в своей домашней папке (`~/`)
- `mkdir: No such file or directory` → использовать `mkdir -p` для вложенных папок

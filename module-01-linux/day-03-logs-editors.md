## Команды Дня 3
- `nano file` — открыть файл в редакторе
- `chmod +x script.sh` — сделать скрипт исполняемым
- `./script.sh` — запустить скрипт
- `cat file` — показать содержимое файла
- `grep pattern file` — найти строки с pattern
- `grep pattern file | wc -l` — подсчитать количество найденных строк
- `tail -f file` — следить за новыми строками в реальном времени
- `sudo tail -f /var/log/auth.log` — следить за логами аутентификации

## Системные логи
- `/var/log/auth.log` — логи входа в систему (SSH, sudo, login)
- `/var/log/syslog` — общие системные сообщения
- `/var/log/kern.log` — сообщения ядра

## Важные моменты
- `grep` ищет строки по шаблону
- `wc -l` считает количество строк
- `tail -f` показывает новые строки по мере их появления
- `Ctrl+C` прерывает выполняющуюся команду

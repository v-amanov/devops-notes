# День 5. Сетевые основы Linux

## Команды, которые я использовал

| Команда | Действие |
|---------|----------|
| `ip a` | Показать все сетевые интерфейсы и IP-адреса |
| `sudo ss -tulpn` | Показать все слушающие TCP/UDP порты с процессами |
| `wget URL -O file` | Скачать файл по ссылке и сохранить с именем |
| `curl ifconfig.me` | Узнать внешний IP-адрес |
| `echo "127.0.0.1 mytest.local" | sudo tee -a /etc/hosts` | Добавить запись в локальный DNS |
| `ping -c 2 host` | Проверить связность (2 пакета) |

## Мои IP-адреса
- Локальный IP: `192.168.137.100` (интерфейс `eth0`)
- Внешний IP: `37.214.56.194`

## Важные моменты
- `ss` показывает открытые порты и процессы, которые их слушают.
- `wget` удобен для скачивания файлов из интернета.
- `curl` — для отправки HTTP-запросов и получения ответа (например, внешнего IP).
- `/etc/hosts` — локальный файл для сопоставления имён и IP (используется до DNS).
- `ping` проверяет доступность хоста по сети.

## Команда `sudo tee -a`

| Часть | Что делает |
|-------|------------|
| `sudo` | Даёт права root для записи |
| `tee` | Читает stdin и записывает в файл + выводит на экран |
| `-a` | Добавляет в конец файла (append), а не перезаписывает |

**Зачем нужна:** чтобы добавить строку в файл, который принадлежит root (например, `/etc/hosts`).

**Почему не работает `>>` с `sudo`:** перенаправление выполняется до вызова `sudo`.

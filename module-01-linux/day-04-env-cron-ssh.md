# День 4. Переменные окружения, Cron, SSH

## 1. Переменные окружения (Environment Variables)

### Что это?
Это именованные ячейки памяти, которые хранят настройки для терминала и программ. 
- `$USER` — ваше имя
- `$HOME` — путь к вашей домашней папке
- `$PATH` — список папок, где искать программы

### Как создать и использовать
| Команда | Действие |
|---------|----------|
| `MY_VAR="hello"` | Создать обычную переменную (живёт только в этой сессии) |
| `export MY_VAR="hello"` | Сделать переменную доступной всем дочерним процессам |
| `echo $MY_VAR` | Вывести значение переменной |
| `env` | Посмотреть все экспортированные переменные |

### Как сделать переменную постоянной
Чтобы переменная не пропадала после перезагрузки, её пишут в файл `~/.bashrc`:
```bash
echo 'export MY_NAME="Vlad"' >> ~/.bashrc
source ~/.bashr
```
## 2. Cron — планировщик задач

### Что это?
Служба, которая выполняет команды автоматически по расписанию.

### Формат строки расписания
Минута Час День Месяц День_недели Команда


### Специальные символы
- `*` — любое значение
- `*/5` — каждые 5 единиц
- `1-5` — диапазон

### Примеры расписаний
| Строка | Значение |
|--------|----------|
| `* * * * *` | Каждую минуту |
| `*/5 * * * *` | Каждые 5 минут |
| `0 3 * * *` | Каждый день в 3:00 |
| `0 9 * * 1` | Каждый понедельник в 9:00 |

### Работа с cron
| Команда | Действие |
|---------|----------|
| `crontab -e` | Открыть расписание для редактирования |
| `crontab -l` | Показать текущее расписание |
| `crontab -r` | Удалить все задачи |

### Моя задача
* * * * * date >> /home/admin-va/cron_test.log

## 3. SSH-ключи (Аутентификация без пароля)

### Что это?
Пара ключей для безопасного подключения к серверам и Git:
- **Приватный ключ** (`id_ed25519`) — ваш секрет. Никому не показывать.
- **Публичный ключ** (`id_ed25519.pub`) — можно показывать всем. Вы кладёте его на сервер, и сервер «узнаёт» вас.

### Как сгенерировать
```bash
ssh-keygen -t ed25519 -C "devops-lab"
```
    На вопрос Enter file in which to save the key — нажмите Enter (сохранится по умолчанию).

    На вопрос Enter passphrase — нажмите Enter (оставляем пустым для учебных целей).

### Как посмотреть публичный ключ
```bash
cat ~/.ssh/id_ed25519.pub
```

## 5. Важные моменты для запоминания

1. **Без `export`** переменная видна только в текущей сессии терминала.
2. **`~/.bashrc`** — файл, который загружается при каждом открытии терминала. Это лучшее место для постоянных настроек.
3. **Cron** использует **абсолютные пути** к командам и файлам (например, `/home/admin-va/cron_test.log`), потому что у него нет переменной `PATH`.
4. **SSH-ключи** — это основа безопасного доступа в DevOps. Приватный ключ никогда не должен попадать в чужие руки.

# День 7. Регулярные выражения, sed, awk

## Регулярные выражения (метасимволы)
| Символ | Значение |
|--------|----------|
| `.` | Любой один символ |
| `*` | Ноль или более повторений |
| `+` | Одно или более повторений |
| `?` | Ноль или одно повторение |
| `[]` | Любой символ из набора |
| `[^]` | Любой символ, кроме набора |
| `^` | Начало строки |
| `$` | Конец строки |
| `()` | Группировка |
| `\|` | ИЛИ |

## grep -E (расширенный поиск)
```bash
grep -E "^Error" app.log          # строки, начинающиеся с Error
grep -E "user[0-9]+" app.log      # user с цифрами
grep -c "ERROR" app.log           # подсчитать количество
```

## sed (замена текста)

# Заменить все IP на [REDACTED]

```bash
sed -E 's/[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+/[REDACTED]/g' app.log > clean.log
```

# Удалить строки с DEBUG
sed '/DEBUG/d' app.log

`s/что/на_что/` — заменить

`g` — все вхождения

`-i` — изменить файл на месте

`-E` — расширенные регулярки

## awk (вырезает столбцы)

```bash
awk '{print $2, $3}' app.log      # 2-й и 3-й столбцы
awk '{print $1}' /etc/passwd      # 1-й столбец
awk -F: '{print $1, $6}' /etc/passwd  # разделитель ":"
```

    $0 — вся строка

    $1, $2... — столбцы (разделитель — пробел по умолчанию)

    -F — указать разделитель

## Комбинирование

```bash
grep "logged in" app.log | awk '{print $5}'   # вытащить 5-й столбец из отфильтрованных строк
```

## Важные моменты

    grep ищет строки, sed заменяет, awk вырезает столбцы

    + в regex означает "одно или более повторений"

    $2 в awk — это второй столбец, а не переменная Bash

## Команды Дня 2
- `chmod +x script.sh` — добавить право исполнения файлу
- `./script.sh` — запустить скрипт из текущей папки
- `sleep 300 &` — запустить процесс в фоне
- `ps aux | grep sleep` — найти процесс по имени
- `kill <PID>` — завершить процесс (SIGTERM)
- `ps aux | grep $USER > my_proc.txt` — сохранить список своих процессов в файл
- `ls /nonexistent 2> error.log` — перенаправить ошибки в файл

## Важные моменты
- Права `rwx` задаются через `chmod`.
- `&` запускает команду в фоне, не блокируя терминал.
- `kill` без `-9` даёт процессу шанс завершиться корректно.
- Потоки: `1>` (stdout), `2>` (stderr), `>` (по умолчанию stdout).
